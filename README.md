# Gradia

技術資料を読みながら、必要な割合の文を日本語で表示し、疑問をその場でAIに質問できるWindowsアプリです。

ソースコード、文字を選択できるPDF、公開Webページを同じライブラリーで扱います。原本を変更せず、読書位置・訳文・会話履歴をこのPCに保存します。

## インストールと起動

1. [最新版のRelease](https://github.com/k-zshiba/Gradia/releases/latest)から、Windows x64用の`Gradia_バージョン_x64-setup.exe`をダウンロードします。
2. インストーラーを実行します。
3. スタートメニューの「Gradia」を開きます。

対応OSはWindows 11 x64です。通常の利用にRustやNode.jsの導入は必要ありません。

## 資料を読む

- 「資料を追加」で複数ファイルを選択できます。「フォルダーを追加」は配下の対応ファイルをまとめて取り込み、「URLから追加」は元のWebページをアプリ内で開きます。
- フォルダー内のサブフォルダーも対象です。`node_modules`・`target`・`.git`などの依存・生成物は除外します。進捗を表示し、読み込めないファイルは最後に理由を表示します。「取り込みを中断」では処理中のファイルを保存してから停止します。
- 左の一覧で資料を切り替え、中央で閲覧・本文検索・目次を利用します。
- PDFの図・表・数式は「原本を開く」から確認します。スキャンPDFは原本閲覧に対応します。
- 取り込み・保存したWeb資料は、その時点の本文を保持します。資料の更新ボタンで取り直すと新しい版になります。
- コードの行番号と構文を表示し、コメントの翻訳は補助表示します。コード自体は編集・実行しません。
- 中央の削除ボタンで、開いている資料の版を削除できます。確認画面で「すべての版」を選ぶこともできます。すべてのプロジェクトから外れ、関連する訳文・会話も削除されます。元ファイルは残ります。進行中の翻訳・回答は中断します。

## Webページを元の表示で読む

「URLから追加」にURLを入力し、「元ページを開く」を押します。元サイトのレイアウト・画像・リンクを使って閲覧できます。戻る・進む・再読み込み・アドレス入力にも対応します。保存済みWeb資料の「元ページ」からも開けます。

日本語の割合を選び、「不足分を翻訳」を押します。PLaMoで翻訳した文を元ページ内に表示します。訳文がある文は、割合や併記モードを変えても再翻訳しません。「原文に戻す」で元の表示へ戻せます。表示後に本文が変わるページは「本文を再解析」で取り直します。

コード・数式要素・フォーム・非表示領域・フレームは翻訳しません。本文の長さと文数に上限があり、一部だけを解析した場合は画面に表示します。太字やリンクで分かれた英文は、それぞれのテキスト部分を翻訳するため、文全体の翻訳と異なる場合があります。

AIに質問するときは保存先を選び、「原文を保存してAIに質問」を押します。取得した原文を資料として保存し、通常の閲覧画面へ移ります。本文だけの保存なので、元サイトのレイアウト・画像・スクリプトのオフラインコピーにはなりません。URL画面の「記事の本文だけを取り込む」も引き続き使えます。

## プロジェクトでまとめる

左上の「プロジェクト」の＋ボタンで、学習テーマごとのプロジェクトを作成します。選択中に追加したファイル・フォルダー・取り込んだWeb資料は、そのプロジェクトに入ります。元ページを開くだけでは資料を追加せず、「原文を保存してAIに質問」で選んだ保存先に追加します。

- プロジェクトを切り替えると、資料一覧も切り替わります。「すべての資料」では全資料を表示します。
- 「既存の資料を選ぶ・外す」で保存済み資料を追加・除外できます。同じ資料を複数のプロジェクトで使えます。
- 管理ボタンで名前の変更・プロジェクトの削除ができます。削除しても資料・訳文・会話履歴は残ります。
- プロジェクトと資料の対応は再起動後も保持します。訳文・読書位置・AI会話は資料の版ごとに保存し、プロジェクト間で共有します。AIが参照するのは、現在の資料の選択箇所や表示範囲です。

## Markdownを読む

`.md`・`.markdown`の資料は、見出し・強調・リスト・引用・表・コードブロックを整形したプレビューで読めます。プレビュー内で日本語の割合を変えたり、英日を併記したりできます。本文検索・目次・AIへの質問も使えます。

以前に追加した資料は「Markdownプレビューに更新」を押すと、保存済みの本文から新しい版を作成します。元ファイルを読み直す必要はありません。過去の版と会話は残り、同じプロジェクトから引き続き開けます。

「フォルダーを追加」でMarkdownと画像を含むフォルダーを選ぶと、`![説明](images/figure.png)`などの相対パスで指定した画像を表示します。参照形式の画像記法にも対応します。親フォルダーの画像も含めたい場合は、それらを含むフォルダーを選んでください。既に取り込んだ資料は、フォルダーを追加し直すと画像付きの版になります。

PNG・JPEG・GIF・WebPに対応し、1枚10 MB、資料1件の画像合計40 MB、参照256件まで取り込めます。画像も保存するため、再起動後や原本が移動した後も閲覧できます。画像の内容が変わると新しい版になります。

コードと数式は原文を保ち、HTMLは実行しません。フォルダー外やリンク経由の画像、外部URL、SVGなどの未対応形式や読み込めない画像は代替テキストで表示します。取り込み時の理由は「取り込み時の注記」で確認できます。リンクは公開Webページと文書内の見出しへの移動に対応します。

## 日本語の割合を調整する

初回は[Windows版llama.cpp](https://github.com/ggml-org/llama.cpp/releases)の`llama-server.exe`と、[PLaMo 3 Translate 2B GGUF](https://huggingface.co/pfnet/plamo-3-translate-2b-GGUF)の`Q4_K_M`モデルを用意します。これらはGradiaに同梱していません。

1. 設定で実行ファイルとGGUFモデルのパスを指定します。
2. CPU実行の場合はGPUレイヤー数を`0`にし、「翻訳エンジンを起動」を押します。
3. 資料の「日本語の割合」を変更します。

0%は原文、100%は翻訳可能な英文をすべて日本語で表示します。50%では対象の英文を1文おきに日本語で表示し、他の割合でも文書全体に分散させます。割合を増やすと日本語の文が増え、同じ割合に戻すと同じ文が選ばれます。文ごとに原文も確認できます。未翻訳の文は原文で表示しながら処理を待ち、翻訳の進捗は表示割合と別に示します。

割合と訳文は資料ごとに保存します。モデル導入後の翻訳はPC内で行います。

「表示モード」のスイッチで「英日を併記」に切り替えると、対象の各英文の下に日本語訳を表示します。訳文が未完成でも原文を読めます。「割合で切り替え」に戻すと、切り替える前の割合で表示します。モードも資料ごとに保存し、どちらのモードでも同じ訳文を使います。コード本体や数式は原文のままです。

## AIに質問する

1. [Codex CLI](https://developers.openai.com/codex/cli/)を導入し、設定で`codex.exe`を指定します。
2. 「ChatGPTに接続」を押し、ブラウザーでサインインと利用許可を完了します。
3. 本文やコードを選択し、右の「参照内容」を確認して質問を送ります。未選択の場合は表示中の本文を参照します。

回答内の「参照」から本文へ戻れます。送信は`Ctrl + Enter`、回答の停止は中断ボタンです。

右上の「新しい会話を作成」で、同じ資料について別の会話を始められます。「会話セッション」で履歴を切り替えます。会話は資料の版ごとに保存し、再起動後も直前の選択を復元します。切り替えると進行中の回答は中断します。以前の履歴は「以前の会話」として引き継ぎます。

「会話を削除」で、選択中の会話を確認して削除できます。対象の回答を中断し、Gradiaに保存した履歴と再開IDを削除します。資料・訳文・他の会話は残ります。最後の会話を削除した場合は「新しい会話を作成」で始め直せます。

ChatGPT契約枠の利用を優先し、APIキーは要求しません。プランの利用権限・上限によって接続できない場合があります。質問時は質問文・参照範囲・会話がOpenAIへ送信されます。AIの回答は原文と照らし合わせてください。

## 新しいバージョンへの更新

起動時にGitHub Releaseの安定版を確認します。新しいバージョンがあれば、更新するかを尋ねます。

- 「はい、更新する」でダウンロードと検証を行い、更新後に自動再起動します。
- 「今は更新しない」で現在のバージョンを使い続けます。ヘッダーのバージョンボタンから再確認できます。
- 資料・設定・モデル・認証・会話履歴は引き継ぎます。実行中の翻訳や回答は更新前に中断します。
- 更新確認の通信に失敗しても、保存した資料の閲覧とローカル翻訳を継続できます。

自動更新導入前のStudy Tool / 0.1.0からは、最初のGradiaを手動でインストールしてください。

## 保存場所と対応範囲

保存先は`%LOCALAPPDATA%\local.study-tool.desktop\`です。旧版との互換性のため、このフォルダー名を維持しています。

UTF-8のコード・テキスト、文字入りPDF、公開HTML記事に対応します。OCR、ログイン必須ページ、コード編集・実行、クラウド同期には対応していません。複雑なPDFの読順は原本でも確認してください。
