## PLaMo実機計測

- モデル: PLaMo 3 Translate 2B Q4_K_M（1,807,202,144 bytes）。公式ファイルのSHA-256と一致。
- llama.cpp: Windows CPU x64 b12110。公式配布物のSHA-256と一致。
- CPU: Intel Core i7-1360P、物理メモリー約15.6 GiB、GPUレイヤー数0。
- 単体プローブでモデル起動約11.9秒。短い英文2例の翻訳は各約3.4秒、3.5秒。
- 例: “Ownership is a set of rules that govern how a Rust program manages memory.” →「所有権とは、Rustプログラムがメモリを管理する方法を規定する一連のルールである。」
- ネイティブ経路でも5文を翻訳し、read_value() と $x^2$ を保持。長文・多数文の処理時間、ピーク使用メモリー、GPU実行は未計測。
- 翻訳リクエストは127.0.0.1のみに送信。ネットワークアダプターを実際に無効にする試験は行っていない。
